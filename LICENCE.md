The intent of the licensing for the n3n project is to ensure that the source
code is always freely available, to avoid concentrating the rights into any
one person or corporation.

The default license for any new self-contained tools or separate modules,
is GPL-2.0-only.

The default license for new contributions to the core n3n library is
LGPL-2.1-only which allows linking with the other GPL-3.0-only files that
exist within the n3n project.

This is shown with the following markup:

SPDX-License-Identifier: LGPL-2.1-only

See the [detailed discussion on licensing](docs/LICENSE.md)
